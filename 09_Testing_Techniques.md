# Testing Techniques

Testing Techniques are different approaches used to verify the quality and functionality of software.

---

# Black Box Testing

## Definition
Black Box Testing is a testing technique where the tester verifies the functionality of the application without knowing the internal code.

### Performed By
QA Tester

### Example
Testing the login page by entering valid and invalid credentials.

### Advantages
- No programming knowledge required
- Focuses on user requirements
- Suitable for functional testing

---

# White Box Testing

## Definition
White Box Testing is a testing technique where the tester has knowledge of the application's internal code, logic, and structure.

### Performed By
Developer

### Example
Testing loops, conditions, and code paths in a program.

### Advantages
- Improves code quality
- Detects logical errors
- Increases code coverage

---

# Grey Box Testing

## Definition
Grey Box Testing is a combination of Black Box and White Box Testing where the tester has partial knowledge of the application's internal structure.

### Example
Testing a module using database knowledge while validating the user interface.

### Advantages
- Better test coverage
- Finds interface and integration defects

---

# Exploratory Testing

## Definition
Exploratory Testing is an informal testing approach where the tester learns, designs, and executes test cases simultaneously.

### Example
Exploring an e-commerce website without predefined test cases to discover unexpected issues.

### Advantages
- Identifies hidden defects
- Encourages creative thinking
- Useful for new applications

---

# Ad-hoc Testing

## Definition
Ad-hoc Testing is an informal testing method performed without documentation or predefined test cases.

### Example
Randomly clicking different buttons and links to check if the application crashes.

### Advantages
- Quick defect detection
- No documentation required
- Useful for finding unexpected issues

---

# Positive Testing

## Definition
Positive Testing verifies that the application works correctly with valid input.

### Example
Logging in with a valid username and password.

---

# Negative Testing

## Definition
Negative Testing verifies that the application handles invalid or unexpected input correctly.

### Example
Logging in with an invalid username or incorrect password.

---

# Summary

| Technique | Purpose |
|-----------|---------|
| Black Box Testing | Test functionality without code knowledge |
| White Box Testing | Test internal code and logic |
| Grey Box Testing | Test with partial code knowledge |
| Exploratory Testing | Simultaneous learning and testing |
| Ad-hoc Testing | Random testing without documentation |
| Positive Testing | Validate expected behavior |
| Negative Testing | Validate error handling |
