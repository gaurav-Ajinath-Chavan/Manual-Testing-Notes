# Verification vs Validation

## Verification

### Definition
Verification is the process of checking whether the software is being developed according to the specified requirements.

### Key Points
- Static Testing
- No code execution
- Performed during development
- Prevents defects

### Examples
- Requirement Review
- Design Review
- Code Review
- Walkthrough
- Inspection

---

## Validation

### Definition
Validation is the process of checking whether the developed software meets the user's needs and works correctly.

### Key Points
- Dynamic Testing
- Requires code execution
- Performed after development
- Detects defects

### Examples
- Functional Testing
- System Testing
- User Acceptance Testing (UAT)

---

# Difference Between Verification and Validation

| Verification | Validation |
|--------------|------------|
| Checks whether the product is built correctly | Checks whether the correct product is built |
| Static Testing | Dynamic Testing |
| No code execution | Requires code execution |
| Prevents defects | Detects defects |
| Performed before Validation | Performed after Verification |
