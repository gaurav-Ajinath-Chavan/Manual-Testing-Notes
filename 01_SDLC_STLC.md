# SDLC (Software Development Life Cycle)

## Definition
SDLC is the process followed to develop software from planning to maintenance.

## Phases
1. Requirement Gathering
2. Planning
3. Design
4. Development
5. Testing
6. Deployment
7. Maintenance

---

# STLC (Software Testing Life Cycle)

## Definition
STLC is the process followed by testers to ensure software quality.

## Phases
1. Requirement Analysis
2. Test Planning
3. Test Case Development
4. Test Environment Setup
5. Test Execution
6. Defect Reporting
7. Test Closure

---

# SDLC vs STLC

| SDLC | STLC |
|------|------|
| Software Development Life Cycle | Software Testing Life Cycle |
| Done by Developers | Done by Testers |
| Focuses on developing software | Focuses on testing software |
| Starts from Requirement Gathering | Starts from Requirement Analysis |
| Ends with Maintenance | Ends with Test Closure |
