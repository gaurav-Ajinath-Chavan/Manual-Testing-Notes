# Defect (Bug)

## Definition
A defect (bug) is a flaw or issue in a software application that causes it to behave differently from the expected result.

---

# Defect Life Cycle

A defect goes through different stages from reporting to closure.

## Stages

1. New
2. Assigned
3. Open
4. Fixed
5. Retest
6. Reopened (if issue still exists)
7. Verified
8. Closed

---

# Bug Report

A Bug Report is a document used to record defects found during testing.

## Bug Report Fields

| Field | Description |
|-------|-------------|
| Bug ID | Unique identifier |
| Bug Title | Short description |
| Module | Feature where bug exists |
| Severity | Impact of the bug |
| Priority | Urgency to fix |
| Steps to Reproduce | Steps to recreate the bug |
| Expected Result | Expected behavior |
| Actual Result | Actual behavior |
| Status | Current bug status |
