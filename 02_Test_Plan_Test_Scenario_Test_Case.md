# Test Plan

## Definition
A Test Plan is a document that describes the testing scope, objectives, strategy, resources, schedule, and activities.

## Contents
- Test Objectives
- Scope
- Testing Strategy
- Test Environment
- Resources
- Schedule
- Entry and Exit Criteria
- Risks

---

# Test Scenario

## Definition
A Test Scenario is a high-level description of what needs to be tested.

### Example
Login with valid credentials.

---

# Test Case

## Definition
A Test Case is a detailed document containing steps, test data, expected result, and actual result used to verify a functionality.

### Test Case Format

| Field | Description |
|-------|-------------|
| Test Case ID | Unique ID |
| Test Scenario | Feature to test |
| Preconditions | Conditions before testing |
| Test Steps | Steps to execute |
| Test Data | Input values |
| Expected Result | Expected Output |
| Actual Result | Actual Output |
| Status | Pass/Fail |

---

# Test Suite

## Definition
A Test Suite is a collection of related test cases.

---

# Test Data

## Definition
Test Data is the input used to execute test cases.
